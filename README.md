This firmware was made for a measurement system to evaluate swashplateless cyclic blade pitch control systems, but it should work for any thrust vectoring / torque based control systems.

For a detailed explanation, part lists, schematics and discussion, please see [the research](https://github.com/MacroMelon/thrust-torque-measurer/blob/master/design_and_characterisation_of_flexible_living_lag-pitch_highes_in_swashplateless_cyclic_blade_pitch_control_systems_fixed_macromelon_smol.pdf) that this measurement system was used for.

If you're interested, also have a look at [the firmware of the swashplateless cyclic blade pitch controller](https://github.com/MacroMelon/swashplateless-cyclic-blade-pitch-controller) that was evaluated.
